## 🚀 Deployment Options

### 1. **Vercel** (Fastest - 1 min)
```bash
npm install -g vercel
vercel
```
Best for: Free, fast, works out of the box

### 2. **GitHub Pages** (Free - 5 min)
```bash
git push origin main
# Enable in repo settings
```
Best for: Free, good for portfolios

### 3. **Netlify** (Easy - 2 min)
Connect GitHub, auto-deploys on push
Best for: Easy setup, good UI

### 4. **Custom Server**
Build: `npm run build`
Start: `npm run start`
Best for: Full control

## 📞 Support

### Getting Stuck?
1. Check QUICK_START.md
2. Check README.md in FOLIO-next
3. Read code comments
4. Google the error message

### Common Issues
- Port already in use? → Use `npm run dev -- -p 3001`
- Dependencies issue? → Delete `node_modules` and reinstall
- Styles broken? → Run `rm -rf .next && npm run dev`
- Post not showing? → Check format in `lib/data/blog.ts`
